# 기능 지원 범위 {#feature-support}

구현 현황이며 SLA가 아닙니다. “구현됨”은 저장소에 코드와 테스트가 있다는 뜻입니다. 운영 환경 증거는 선택한 배포에서 확보해야 합니다.

| 기능 | 상태 | 범위·남은 검증 |
| --- | --- | --- |
| Messages·Chat Completions·Responses·Bedrock 수신 | 구현됨 | 공급자·기능 조합별 차이 |
| 가상 키·모델 허용 목록·팀 제한 | 구현됨 | 발급·관리 경로와 저장소 접근 보호 필요 |
| 검증된 사용자·서비스 신원 | 선택적 활성화 | 과거 바인딩 검토와 필수 모드 배포 검증 필요 |
| 영속 전역 정책 금전 예산 | 선택적 · ADR-045/046 | 보수적 예약, 불명확한 사용량은 의무 유지 |
| 전역 RPM·TPM·토큰 할당량 | 선택적 · ADR-046 | 동기식 Postgres 의존성 |
| 민감 정보 정책·적응형 라우팅 | 선택적 | 유한한 탐지기, 운영자 선언 경계, 로컬 세션 고정 |
| 해시 체인 감사·선택적 앵커링 | 구현됨 | 각 인스턴스 구간 보존, WORM은 저장소·IAM에 의존 |
| 메트릭·트레이스·사용 분석 | 구현됨 | 별도 채널, 수집기·보존 설정 필요 |
| 조직·팀 범위의 관리 역할 6개 | 미완료 | 현재 자격 증명·관리자 구분은 더 거침 |
| 완전한 사용자별 프리미엄·총예산 풀 계약 | 미완료 | 기존 티어·하드 한도는 구성 요소 |
| 미확정 잔액 자동 조정 | 미완료 | 카운터 초기화로 복구하면 안 됨 |
| 서명된 릴리스·운영 HA·부하 검증 | 미완료 | CI만으로 전체 배포를 검증할 수 없음 |
| 임베딩·이미지/오디오 생성·리랭크·MCP 게이트웨이 | 현재 제품 범위 밖 | 채팅·코딩 트래픽에 집중 |

## 호환성 정책 {#compatibility-policy}

프로젝트는 알파이고 API는 `v1alpha1`입니다. 설정·스키마 호환성은 바뀔 수 있습니다. 검토된 커밋이나 내부 빌드 이미지를 고정하고, 기능이 요구하면 참여 바이너리와 CRD를 함께 업그레이드하세요. 운영 전 단계적 인수 검증이 필요합니다.

[배포 프로파일](deployment-profiles.md)과 [상용화 준비도](../operations/production-readiness.md)를 기준으로 판단하세요. [로드맵](../roadmap.md)은 구현된 메커니즘과 남은 계약을 구분합니다.
